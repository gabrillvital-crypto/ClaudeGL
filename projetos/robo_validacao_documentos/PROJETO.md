## O que é este projeto

Proposta de uma funcionalidade nova para a plataforma Efcaz: um módulo automatizado que valida documentos enviados por fornecedores sem intervenção humana — usando OCR, classificação de documentos e cruzamento com o cadastro da plataforma.

A dor é generalizada na carteira: todos os clientes têm equipes dedicadas (2 a 15 pessoas) para validar documentos manualmente. As buscas automáticas já resolvem as certidões públicas, mas todo o restante ainda depende de validação humana.
