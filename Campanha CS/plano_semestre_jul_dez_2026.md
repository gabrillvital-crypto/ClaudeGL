## Fases de segmentação

### Fase 1 — Geral (Emails 1 e 2)
Objetivo: validar a base, medir abertura, identificar contatos desatualizados.
Critério de sucesso: taxa de abertura >25%, bounce <5%.

### Fase 2 — Segmentado por uso (Emails 3 em diante)
Critérios de segmentação a usar no RD Station:
- **Perfil A:** usa homologação, sem Terceiros ativo
- **Perfil B:** usa homologação + Terceiros
- **Perfil C:** usa homologação + Terceiros + RFI
- **Decisores sem acesso à plataforma:** segmento separado para emails de visibilidade gerencial

### Fase 3 — Por comportamento (Nov/Dez)
Baseado nos dados acumulados:
- Abriu 3+ emails → cliente engajado → prioridade para expansão
- Abriu mas nunca agendou → ligar/WhatsApp
- Nunca abriu → verificar contato, acionar via outro canal
