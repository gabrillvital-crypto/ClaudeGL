# Linha de Fornecimento — O que é e como funciona

**KB de referência:** KB90015 / KB99015
**Seção:** Jornada do Fornecedor (passo 3 do cadastro)
**Público:** Fornecedores e usuários contratantes

---

## O que é linha de fornecimento?

Linha de fornecimento é a **categoria específica do produto ou serviço** que um fornecedor oferece para a empresa contratante. É o campo que responde à pergunta: "o que exatamente essa empresa fornece para nós?"

Ela é diferente do **ramo de atividade**, que é mais genérico (ex: "Indústria farmacêutica"). A linha é específica (ex: "Vitaminas", "Anti-hipertensivos", "Serviço de manutenção elétrica").

**Exemplos práticos:**

| Ramo de Atividade (geral) | Linha de Fornecimento (específica) |
|---|---|
| Indústria farmacêutica | Vitaminas — 0214 |
| Serviços gráficos | Impressos Diversos — 0858 |
| Publicidade | Serviço de Publicidade, Impressão e Encadernação — 073 |
| Construção | Materiais de construção civil |

A linha pode ser **Material** (produto físico) ou **Serviço** (prestação de serviço).

---

## Para que serve na plataforma?

A linha de fornecimento tem dois papéis na Efcaz:

1. **Organização e segmentação:** permite que a empresa contratante agrupe e filtre fornecedores por categoria de compra.
2. **Gestão de Terceiros:** colaboradores (terceiros) precisam estar associados a uma linha de fornecimento para que os documentos exigidos sejam corretamente vinculados. Cada linha com prestação de serviço deve ter ao menos 1 colaborador associado.

---

## Quem cadastra as linhas disponíveis?

A **empresa contratante (cliente)** é quem cadastra e define quais linhas de fornecimento estarão disponíveis na plataforma. O fornecedor só pode selecionar entre as opções que o cliente disponibilizou.

> Se uma linha que o fornecedor precisa não aparece no cadastro, ele deve entrar em contato com a empresa contratante para solicitar a inclusão.

---

## Como o fornecedor insere a linha de fornecimento (passo a passo)

**Pré-requisito:** precisa existir uma solicitação em aberto. A tela inicial deve mostrar um dos botões: **Continuar Preenchimento**, **Resolver** ou **Alterar**.

> **Atenção:** se o status for "Aguardando análise" ou "Em análise", não é possível fazer alterações até a conclusão da análise.

**Passos:**

1. Na tela inicial, clique em um dos botões disponíveis
2. Acesse o menu lateral: **Geral > Linha de Fornecimento**
3. Clique em **Adicionar Linha**
4. Busque por código ou descrição, ou filtre por **Material** / **Serviço**
5. Selecione a linha desejada e clique em **Salvar**
6. Repita para adicionar mais linhas, se necessário
7. Ao finalizar todo o cadastro, clique em **Enviar para Aprovação**

> O botão "Adicionar Linha" pode aparecer bloqueado se o cliente não permite que o fornecedor altere essa informação. Nesse caso, o cliente deve fazer a alteração diretamente.

## Dúvidas frequentes

**Por que não consigo alterar a linha de fornecimento?**
Dois motivos possíveis: (1) o cadastro está em análise — aguarde a conclusão; (2) o cliente bloqueou a edição — entre em contato com a empresa contratante.

**Posso adicionar mais de uma linha?**
Sim. Adicione quantas linhas forem necessárias para representar corretamente os serviços ou materiais da empresa.

**Posso remover uma linha depois de adicionar?**
Sim, desde que o cliente não tenha bloqueado essa edição. Exclua a linha antes de enviar para aprovação.

**O que acontece depois de enviar para aprovação?**
A empresa contratante irá analisar as informações. Se houver ajustes, o cadastro retorna com pendências para correção.

---

## Como explicar para o cliente (empresa contratante)

Quando um cliente perguntar o que é a linha de fornecimento, use esta analogia:

> "É como uma etiqueta de categoria que você coloca em cada fornecedor. Em vez de saber só que aquela empresa é 'do setor químico', você sabe exatamente que ela fornece 'Lubrificantes Industriais' ou 'Produtos de Limpeza'. Isso facilita na hora de filtrar quem fornece o quê e de organizar os documentos por tipo de fornecimento."

**Perguntas que o cliente pode fazer:**

| Pergunta | Resposta objetiva |
|---|---|
| "Quem define quais linhas ficam disponíveis?" | Você (cliente). Vai nas Configurações > Linhas de Fornecimento. |
| "O fornecedor pode criar uma linha nova?" | Não. Ele só seleciona entre as que você disponibilizou. |
| "Posso bloquear para o fornecedor não alterar?" | Sim. Nas configurações da plataforma é possível bloquear essa edição. |
| "Preciso preencher isso no onboarding?" | Sim, é uma das parametrizações iniciais mais importantes — define como você vai organizar e segmentar sua base. |

---

## Como o cliente cadastra as linhas disponíveis

Caminho: **Configurações > Linhas de Fornecimento** (KB90036)

O cliente define o catálogo de linhas que os fornecedores poderão selecionar. Recomendação: levantar com a área de compras quais categorias de produtos/serviços a empresa utiliza e cadastrar antes de convidar os fornecedores.
